## 📚 Assignments

### 1. Reliable UDP Communication

Implementation of reliable data transfer over UDP using **ACKs, sequence numbers, timeouts, and retransmissions**. The system is tested under different packet-loss conditions using Mininet.

**Technologies:** Python, UDP, Socket Programming, Mininet

### 2. TCP Client-Server Communication

Implementation of a basic **TCP client-server application** to understand connection-oriented and reliable data communication.

**Technologies:** Python, TCP, Socket Programming

### 3. Raw Socket Packet Analysis

A **C-based raw socket program** for capturing and analyzing TCP packets. Packet information is verified using Wireshark.

**Technologies:** C, Raw Sockets, TCP, Wireshark

### 4. Multi-Client Chat Server

A TCP chat application that allows **multiple clients to connect and communicate simultaneously** through a central server.

**Technologies:** Python, TCP, Multithreading

### 5. Advanced Chat Server

An enhanced chat application supporting **broadcast messaging, private messaging, chat history, and performance analysis**.

**Technologies:** Python, TCP, Multithreading

### 6. GUI Chat Application

A graphical TCP chat application with a user-friendly interface for **client connection, broadcast messaging, and private messaging**.

**Technologies:** Python, Tkinter, TCP, Wireshark

### 7. Secure TCP Application

A secure version of the chat application implementing **authentication, password hashing, login protection, session management, and security logging**.

**Technologies:** Python, TCP, Authentication, SHA-256
