ISEA Phase-III Summer Internship – Tezpur University

This repository contains all the coursework, programming assignments, and documentation completed as part of the online Summer Internship under the **Information Security Education and Awareness (ISEA) Project Phase-III**, hosted by **Tezpur University**.

Contents & Assignments

* **Assignment 1:** Reliable UDP data transfer implementation using Python and Mininet (handling packet loss and acknowledgments).
* **Assignment 2:** Network topology configuration, emulation, and traffic routing analysis using Mininet.
* **Assignment 3:** Project Report, analysis, and supporting implementation code.
* **Assignment 4:** Implementation of custom socket communication protocols and packet inspection.
* **Assignment 5:** Client-server multi-client communication and message routing mechanisms.
* **Assignment 6:** Socket programming, network tasks, and multi-user chat server implementation.
* **Assignment 7:** Secure TCP communication implementation and cryptographic data integrity checks.
* **Assignment 8:** Optimized TCP performance, throughput evaluation, and congestion control analysis.

Technologies & Tools
* **Language:** Python
* **Networking & Emulation:** Mininet, Socket Programming, TCP/UDP Protocols, Wireshark
* **Environment:** Linux / Ubuntu
